# Aurex Roadmap

GitHub tracking issue: https://github.com/juanpimr2/aurex/issues/1

## Phase 1: Runtime Safety

Issue: https://github.com/juanpimr2/aurex/issues/2

- DEMO/REAL fail-closed mode.
- Broker mutation double opt-in.
- Legacy runtime disabled by default.
- Safe sizing and guard tests.

## Phase 2: Repo Hygiene And SDD

Issue: https://github.com/juanpimr2/aurex/issues/3

- Updated README and docs.
- PR and issue templates.
- Council rules and SDD workflow.

## Phase 3: Dashboard Foundation

Issue: https://github.com/juanpimr2/aurex/issues/4

- Read-only operations dashboard.
- Runtime gates and strategy cards.
- No broker mutation controls.

## Phase 4: Reconciliation And Observability

Issue: https://github.com/juanpimr2/aurex/issues/5

- Broker/local reconciliation.
- Canonical P&L source.
- Structured health and session events.

## Phase 5: CI And Release Discipline

Issue: https://github.com/juanpimr2/aurex/issues/6

- Backend tests in CI.
- Frontend build validation.
- PR safety checklist.

## Phase 6: Council Providers

Issue: https://github.com/juanpimr2/aurex/issues/7

- Codex as orchestrator/tech lead.
- Claude as developer provider when available.
- Provider fallback without pretending unavailable agents participated.
